\begin{abstract}
Map-conditioned wireless models are usually trained and evaluated on correctly
matched signal--scene pairs.  Such performance does not specify how their
representations should change when local geometry changes while receiver state
and radio configuration are held fixed.  We formulate a paired audit that
separates physically effective (active), ambiguous (gray), and below-noise
(null) map interventions, and introduce \method{}, a supervision framework on
reusable scene-level world banks.  For each Hamming-1 scene edit, Alignment asks
which adjacent map better explains the observed channel, whereas Response
predicts the ray-traced target channel under a signed edit.  Both objectives
update one retained map-conditioned state encoder; Response uses the clean,
pair-consistent physical CSI patch as its primary target and a frozen-teacher
latent patch as an auxiliary target, while the CSI-only teacher audits route sensitivity,
and the headline model never receives receiver position.  We specify a strict $2\times2$ experiment, scene-clustered
statistics, shortcut controls, and claim-evidence gates that distinguish local
paired sensitivity from global map validity, joint supervision from extra
compute, and simulator-defined effects from real-world causality.  A decisive
no-position Response qualification compares oracle-$x$, no-$x$, copy,
no-action, action-swap, map/edit-only, and null behavior.  The frozen
\texttt{9850fff} two-city localization has already been executed as a
historical negative (G5 FAIL); same-data C1 meters remain unrun.
\end{abstract}

\section{Introduction}

Channel state information (CSI) contains a structured record of propagation
through the physical environment.  Recent channel foundation models learn from
masked CSI reconstruction or multiple deterministic views of the same channel
\citep{jiang2026csimae,jiang2025csiclip,jiang2026csiclippp}, while multimodal
systems combine signals with scene geometry or motion
\citep{chen2026wwm,chu2026sigmap}.  These objectives can yield useful matched-pair
representations.  They do not, by themselves, identify how a representation
should respond to an intervention on the scene: two predictors can agree on
every observed zero-edit example and disagree arbitrarily after a wall is
inserted, removed, or changed.

The distinction matters for localization.  A map-conditioned predictor can use
coarse city context, scene identity, or map artifacts without encoding the
local geometry responsible for a particular channel.  Conversely, degradation
under an arbitrary wrong map does not prove physical grounding: the corruption
can lie far outside the training distribution, while some local edits have no
measurable effect at the receiver.  A useful audit must therefore hold the
receiver state, radio configuration, and propagation nuisance variables fixed;
retrace the edited world; and avoid labeling every alternate map as physically
incompatible.

We study this problem with \emph{paired scene interventions}.  A scene-level
world bank contains canonical states of a small edit hypercube and is reused
across many receiver positions.  Only adjacent Hamming-1 worlds are compared.
Each edge-position unit receives a physical primary route and an independent
frozen-teacher sensitivity stratum.  Active physical edges support relative
Alignment; gray physical edges carry target regression but no strong
compatibility label; null physical edges receive a tolerance constraint rather
than a negative label.  Teacher strata audit target quality without selecting
the raw-CSI primary sample set.

\method{} adds two distinct constraints to a shared state encoder.  Alignment
selects the generating side of an active paired edge.  Response predicts the
direction and magnitude of the retraced raw-CSI target under a signed edit.  The
target is loaded only after source inputs are fixed; the auxiliary teacher reads
CSI only, preventing the target map or receiver coordinate from leaking the answer.
At localization time, only the retained state encoder and
position head remain.  The method therefore succeeds only if both skills are
present in the shared representation, not merely in disposable audit heads.

This evidence-gated V2.1 draft makes three methodological contributions:

\begin{itemize}
    \item We define a six-condition wrong-map audit and a paired compatibility
    protocol that distinguish active, gray, and null edits from arbitrary
    wrong-city, geometry-destroyed, and empty-map stress tests.
    \item We formulate node-balanced, bidirectional scene-level world banks and
    shared Alignment/Response supervision with a physical CSI target, an
    auxiliary CSI-only teacher target, no receiver position in the headline
    input, and explicit null dead zones.
    \item We preregister a strict $2\times2$ comparison, equal-resource and
    shortcut controls, and scene-level inference.  Whether joint supervision
    is better than the single branches is decided by localization meters and
    same-data baselines, not by whether a gate licenses the discussion.
\end{itemize}

Qualification and the strict four-arm factorial have been executed.  The
central empirical question is no longer whether those stages may start.
It is whether the retained representation improves unseen-city meters
relative to the single branches and to in-repository same-data baselines.
The executed factorial is a historical negative result under the frozen
recipe; that record stays visible while the recipe is revised.

\section{Related Work}

\paragraph{Wireless self-supervision and world models.}
CSI-MAE masks and reconstructs CSI to learn channel representations
\citep{jiang2026csimae}.  CSI-CLIP and CSI-CLIP++ align frequency-domain CSI
with its delay-domain CIR view \citep{jiang2025csiclip,jiang2026csiclippp}.
The Wireless World Model combines CSI, point clouds, and trajectories through
same-world predictive learning \citep{chen2026wwm}.  These are strong starting
points, but same-world completion and deterministic transforms of one channel
do not supervise the response to a retraced scene edit.  When source code is
unavailable, our protocol labels the corresponding control
``WWM-inspired same-world matched prediction'' to distinguish it from a
faithful reproduction.

\paragraph{Map-conditioned localization.}
SigMap uses a geographic map as a prompt for cross-scenario wireless
localization \citep{chu2026sigmap}.  This makes it a direct diagnostic neighbor:
our question is not whether a map improves matched localization, but whether
the model responds correctly to local paired edits and remains stable on null
edits.  We evaluate external methods only under accurately named implementation
status---official-code adaptation, paper-spec controlled implementation, or
inspired control---and do not transfer numbers across datasets.

\paragraph{Geometry-aware wireless prediction.}
PMNet predicts pathloss radiomaps from building and transmitter maps
\citep{lee2023pmnet}; Wi-GATr predicts wireless quantities from scene primitives
and transmitter/receiver geometry \citep{hehn2024wigatr}; WiSER predicts radiomaps and CIRs
from a transmitter-conditioned scene memory \citep{qiao2026wiser}; RF inverse
rendering explicitly models editable geometry and materials
\citep{wang2026rfir}.  These works motivate geometry-aware forward modeling.
Their information budget differs from our headline setting: receiver position
is excluded from \method{} and appears only in a privileged oracle.  Our
contribution centers on paired supervision and an evidence protocol for the
retained localization representation, rather than a new ray tracer or ranking
loss.

\section{Paired Problem Setup}

\subsection{Simulator-defined physical units}

Let $b$ index an independent scene tile, $u$ a world state, $x$ a receiver
position, $c$ the radio configuration, and $\xi_{\mathrm{phys}}$ all propagation
nuisance variables that must remain shared across a pair.  A deterministic
ray-tracing backend produces the noise-free channel
\begin{equation}
    \csi^{\star}_{b,u}(x,c,\xi_{\mathrm{phys}})
    =\mathcal{R}(\map_{b,u},x,c,\xi_{\mathrm{phys}}).
\end{equation}
An observed CSI sample adds an independently seeded observation process.  For
an intervention $u\leftrightarrow v$, the two calls share
$(b,x,c,\xi_{\mathrm{phys}})$ and differ only in one registered scene primitive.
This is a simulator-defined paired unit.  It does not establish a real-world
counterfactual without an external engine or controlled measurement.

\subsection{Reusable scene-level world banks}

Each bank has $K=2^d$ canonical worlds indexed by $u\in\{0,1\}^d$.  A bit
selects one of two physically admissible states for a registered primitive.
Every world is rendered from its complete state description, never by replaying
an edit history.  The bank reuses one common receiver set $X_b$ across all
worlds, and all siblings remain in the same split.  Training uses only
\begin{equation}
    E_b=\{\{u,v\}:\operatorname{Ham}(u,v)=1\},
\end{equation}
with both directions sampled equally.  Sampling is uniform over bank, node,
position, and response query in that order.  This construction removes the
direct shortcut in which a per-position map uniquely identifies $x$, while
unseen-bank, map-only, scene-ID, and variant-ID controls test residual shortcuts.

\subsection{Effect routing}

Let $\Phi_A(\csi)$ be the normalized full-channel physical representation,
$\Phi_R^q(\csi)$ its query-patch restriction, and let
$z_A=\teacher_A(\csi)$ and $z_R^q=\teacher_R^q(\csi)$ be the corresponding
frozen CSI-only teacher representations.  Source-only constants normalize the
two pairs of symmetric distances
\begin{equation}
 \begin{aligned}
 \delta^A_{uv}&=d_{\mathrm{phys}}(\Phi_A(\csi_u),\Phi_A(\csi_v)), &
 \gamma^A_{uv}&=d_z(z_{A,u},z_{A,v}),\\
 \delta^{R,q}_{uv}&=d_{\mathrm{phys}}(\Phi_R^q(\csi_u),\Phi_R^q(\csi_v)), &
 \gamma^{R,q}_{uv}&=d_z(z^q_{R,u},z^q_{R,v}).
 \end{aligned}
\end{equation}
Physical thresholds come from source repeat noise and a source-only
practical-effect floor, then remain frozen:
\begin{equation}
\route_{\mathrm{phys}}(\delta)=
\begin{cases}
\mathrm{null}, & \delta\le\epsilon_0,\\
\mathrm{active}, & \delta\ge\epsilon_1,\\
\mathrm{gray}, & \text{otherwise}.
\end{cases}
\label{eq:route}
\end{equation}
Alignment uses $\route_A(u,v)=\route_{\mathrm{phys}}(\delta^A_{uv})$;
patch-level Response training and the unified retained-state probe use the
separate query-level route
$\route_R(u,v,q)=\route_{\mathrm{phys}}(\delta^{R,q}_{uv})$, with separately
frozen Alignment and Response thresholds.  Thus a full-channel active edge need
not make every Response query active.  The teacher distance is binned
independently as null, gray, or sensitive using $(\tau_0,\tau_1)$; this stratum
never changes primary inclusion.  Route labels control losses and audit strata
but are never model inputs.  We report raw counts and scene coverage,
physical-active/teacher-sensitive agreement, physical-null/teacher-null
agreement, and teacher-blind physical-active outcomes.  Empty conditional means
are qualification failures, not zeros.  Frozen V6 separately defines the native
mask-cover diagnostic on full-channel $\route_A=\mathrm{active}$ transitions:
it assembles every predicted patch before scoring the complete channel.  This
transition-level diagnostic and the $\route_R$ patch probe are distinct
estimands.

\subsection{What compatibility means}

For an active edge $\{u,v\}$ at a fixed physical unit, the matched pairs are
$\{(\csi_u,\map_u),(\csi_v,\map_v)\}$ and paired alternatives are
$\{(\csi_u,\map_v),(\csi_v,\map_u)\}$.  CSI and map marginals are identical
between labels.  A fixed-budget probe score on this support defines
\emph{compatibility decodability}, not global physical validity.  Gray edges do
not enter active AUROC.  Null edges are evaluated for over-discrimination, not
treated as negatives.  Wrong-city, geometry-destroyed, and empty maps are
stress tests and receive no calibrated probability unless their corruption
families were included in source-only calibration.

\section{CSI-PAIRS}

\subsection{Shared retained state}

For CSI from world $i$, a supplied candidate map from world $j$, and mask $m$,
define the retained state
\begin{equation}
 C_{i\mid j}^m=\enc\!\left(V_m(\csi_i),G(\map_j),c,m\right),
\end{equation}
with $C_u^m:=C_{u\mid u}^m$.  Here $V_m$ exposes only unmasked source CSI, $G$ is a map encoder, and the
fusion module is shared by every arm.  A predictor $P_\psi$ receives
$(C_u^m,e_{uv},q)$, where $e_{uv}$ encodes the signed primitive edit and $q$ is
a target query.  Zero action gives an identity prediction.  The V2.1 primary
target $y_v^q=\Psi(\csi_v)^q$ is the source-normalized clean raw-CSI patch under
the pair-consistent gauge.  Concretely, every sibling world at fixed $(b,x)$ is
rendered under the same registered complex reference $r_{b,x}$; $\Psi$ applies
that shared reference, the frozen antenna/subcarrier ordering and patching, and
source-training mean/scale statistics.  It performs no per-world phase fitting.
The auxiliary target $t_v^q=\teacher_R^q(\csi_v)$ is stop-gradient and frozen.
The physical target is primary; the teacher target audits and regularizes the
retained state but cannot replace physical success.  Target CSI, position,
route, and labels cannot enter a source predictor.

After pretraining, action encoder, predictor, teacher, and audit readouts are
discarded.  Localization uses only
\begin{equation}
 r=\enc(\csi,\map,c),\qquad \widehat{x}=g(r),
\end{equation}
where $g$ is trained with the same source-position labels and update budget for
all arms.  Thus any downstream difference must pass through the shared state.

\subsection{Common endpoint objective}

All four arms first learn the same matched endpoint objective.  For a frozen
query bank $Q(m)$ with $q\in m$,
\begin{equation}
 \mathcal{L}_{B}=\E_{b,u,x,m,q}
 \rho_y\!\left(P_\psi(C_u^m,e_{uu},q),y_u^q\right).
\end{equation}
Any common raw-CSI reconstruction term is identical across arms.  Endpoint is
therefore both a useful initialization and the $00$ arm in the factorial test;
it is not evidence of intervention response.

\subsection{Paired Alignment}

The same predictor defines an intrinsic energy
\begin{equation}
 \score(\csi_u,\map_v)
 =-\frac{1}{|Q|}\sum_{q\in Q}
 \rho_{\mathrm{end}}\!\left(P_\psi(C_{u\mid v},e_{vv},q),(t_u^q,y_u^q)\right),
\end{equation}
where $\rho_{\mathrm{end}}=\rho_z+\lambda_y\rho_y$ is frozen across arms and
the candidate map enters only through the supplied-map state $C_{u\mid v}$.
On an active undirected edge, the symmetric margin loss is
\begin{align}
 \ell_A^{uv}={}&
 [m_{uv}-\score(\csi_u,\map_u)+\score(\csi_u,\map_v)]_+\\
 &+[m_{uv}-\score(\csi_v,\map_v)+\score(\csi_v,\map_u)]_+.
\end{align}
The margin is fixed or a source-frozen monotone function of physical effect.
For null edges we instead penalize score gaps beyond a no-edit tolerance
$\kappa_s$; gray edges receive no Alignment loss.  Expectations first average
within eligible banks and then across banks so route prevalence cannot silently
reweight scenes.

\subsection{Intervention Response}

For every directed edge, including active, gray, and null, the predictor emits
$(\widehat t,\widehat y)$ and regresses the retraced physical target plus the
frozen auxiliary latent target:
\begin{equation}
 \ell_{\mathrm{target}}^{uv,m,q}
 =\rho_z\!\left(\widehat t_{u\rightarrow v}^{m,q},t_v^q\right)
 +\lambda_y\rho_y\!\left(\widehat y_{u\rightarrow v}^{m,q},y_v^q\right).
\end{equation}
Let $\widehat{\Delta y}_{uv}=\widehat y_{u\rightarrow v}-
\widehat y_{u\rightarrow u}$ and $\Delta y_{uv}=y_v-y_u$. Active edges add
direction-and-magnitude regression
\begin{equation}
 \ell_\Delta^{uv}=\rho_y(\widehat{\Delta y}_{uv},\Delta y_{uv}).
\end{equation}
Null edges still regress their exact target but penalize hallucinated changes
outside source-frozen dead zones:
\begin{equation}
 \ell_{0R}^{uv}=
 [\|\widehat{\Delta y}_{uv}\|_{\mathrm{phys}}-\kappa_y]_+^2.
\end{equation}
Gray edges carry only target regression.  The target-world CSI is used to form
frozen targets, physical primary routes, teacher audit strata, and metrics; it
never enters a source predictor.

\subsection{Factorial objective}

Let $a,r\in\{0,1\}$ enable Alignment and Response.  Each arm optimizes
\begin{equation}
 \mathcal L_{a,r}=\mathcal L_B+a\lambda_A\mathcal L_A
 +r\lambda_R\mathcal L_R.
\end{equation}
The four arms share initialization, backbone, raw world banks, teacher,
mask/query bank, source-only selection budget, downstream head, and random
draws.  Factor weights are normalized from a source-only pilot and remain the
same in a single branch and Full.  We report effective updates, gradient norms,
parameters, FLOPs, and wall time.  Full is a valid headline only if the two
single branches first solve their own tasks, Full preserves both, and
equal-resource/mechanical-concatenation controls do not explain downstream
performance.

\section{Identification and Testable Implications}

\paragraph{Matched support leaves intervention response underdetermined.}
Correct-pair training identifies zero-action behavior.  Any two predictors equal
almost everywhere on that support have the same matched risk while allowing
different extensions to nonzero action.  Paired retraced targets supply the
missing off-support constraint.

\paragraph{Symmetric quartets match unimodal marginals.}
For an active edge, matched and alternative quartets each contain
$\{\csi_u,\csi_v\}$ and $\{\map_u,\map_v\}$.  Therefore a CSI-only or map-only
statistic cannot solve the label.  Joint world-ID matching remains possible and
must be tested empirically through bank reuse, unseen banks, and ID controls.

\paragraph{Response specifies more than rank.}
Zero active ranking loss requires matched scores to exceed alternatives by a
margin.  Exact identity and target regression additionally imply
$\widehat{\Delta z}_{uv}=\Delta z_{uv}$.  This is a directional and magnitude
constraint; the preregistered factorial interaction measures whether the two
tasks are synergistic.

\paragraph{Action and source-CSI value are empirical questions.}
For state $S$, edit $A$, and target $Z$, squared-loss Bayes risks satisfy
\begin{equation}
R_{\mathrm{noA}}^*-R_A^*
=\E\!\left[\operatorname{tr}\operatorname{Cov}
(\E[Z\mid S,A]\mid S)\right]\ge0.
\end{equation}
The inequality is strict only if conditional targets vary with action.  It does
not guarantee that a learned action encoder avoids collapse.  Likewise adding
visible source CSI cannot increase Bayes risk over map/edit-only input, but the
Bayes result does not guarantee that a finite model uses it.  No-action,
action-swap, map/edit-only, CSI-only, and privileged-$x$
experiments are therefore required.

\subsection{Questions and independent units}

The experiment answers five questions in order.  RQ1 asks whether at least two
C1-eligible map-conditioned models exhibit an active/null wrong-map pattern.  RQ2
asks whether Alignment learns paired compatibility without null
over-discrimination.  RQ3 asks whether masked no-position Response predicts
retraced targets better than copy, no-action, and action-swap in each held-out
selection scene.  RQ4, reached only after the earlier gates, asks whether Full
improves localization in two unseen cities beyond both single branches and
resource-matched controls.  RQ5 asks whether, on a frozen paired-proposal set
and strict $k=0$ common support, separately calibrated localization-failure
risk improves AURC over random and compatibility-only baselines while retaining
registered calibration, coverage, and monotonicity properties.

The highest independent unit is the scene tile/world bank.  All positions,
worlds, edges, directions, masks, and augmentations from a bank remain in one
cluster.  We first compute within-bank numerators, denominators, and location
summaries, then perform scene-macro aggregation and scene-cluster bootstrap.
Position-level confidence intervals are descriptive only and never substitute
for independent scenes.

\subsection{Six-condition map audit}

For fixed channel samples and denominators, each model receives: correct map,
paired active alternative, paired null alternative, wrong-city map,
geometry-destroyed map with preserved low-order statistics, and empty map.
Primary localization outcomes are median and P90 error, reported per city and
bank.  Physical-active compatibility uses a frozen, equal-budget probe AUROC.  Gray
score gaps and null over-discrimination are separate.  The latter three
arbitrary corruptions are stress tests, not paired causal evidence.

\subsection{Metrics and gates}

Alignment's primary diagnostic is active paired CGS AUROC under a unified
probe; native Response's primary diagnostic is target-free full-channel NMSE on
$\route_A$-active transitions, while the unified Response probe reports
$\route_R$-active physical-patch NMSE.  Secondary Response metrics include latent NMSE, delta
cosine, magnitude ratio, and null hallucination.  Localization reports
median/P90 at $k\in\{0,8,32,128\}$ unique target positions, with support and
query siblings isolated.  The paired-proposal failure score reports AURC,
ECE, Brier, and NLL only on frozen source-calibration support; arbitrary
single-map deployment is outside this probability claim.

The gate order is: (i) each single branch beats its task control; (ii) Full is
non-inferior on both native skills; (iii) Full improves preregistered
$-\log$ bank-median localization utility over both single branches; (iv) the
factorial interaction is positive; and (v) no target city or $k=0/8$ setting
has an excessive reverse effect.  Multiplicity within a gate is controlled by
Holm correction or simultaneous scene-cluster intervals.  A failed upstream
gate makes downstream tests exploratory.

\section{Limitations and Conclusion}

\paragraph{Limitations.}
The protocol restricts primary evidence to paired interventions generated by a
qualified simulator; G8 evaluates transfer to an independent engine.  Physical
targets and teacher/physical agreement diagnose teacher blind spots, while the oracle-$x$
gap measures ambiguity from hidden receiver position.  Compatibility is scoped
to the frozen paired proposal set.  Scene-bank inference reflects the available
independent sample count, and resource-matched controls separate supervision
value from additional compute.

\section*{Ethics Statement}
Wireless localization can expose sensitive movement and location information
and can be used for surveillance.  Any real measurements must follow consent,
privacy, institutional, and data-governance requirements.  Released artifacts
must remove device identifiers, private coordinates, credentials, and
proprietary infrastructure paths.  Licenses and permitted uses for maps,
simulator assets, datasets, and baseline code must be documented.  The method
is not a safety or deployment certification.

\paragraph{Conclusion.}
\method{} turns a vague expectation---that a map-conditioned wireless model
should react to geometry---into a paired, routed, and falsifiable supervision
problem.  Scene-level reuse restricts position lookup; symmetric active
quartets support relative Alignment; physical and teacher targets define
Response; and strict controls ask whether the information survives in the
retained localization state.  Qualification and the strict $2\times2$
factorial are complete.  Under the frozen recipe the executed factorial is
a historical negative result: Response-only has the highest primary macro
utility ($-2.5385957759$), Full is $-2.6657030121$, the interaction is
$-0.112904$ (FAIL), and G5 fails ($1/4$).  Full is not first; the old G5
FAIL stands.  The next work is to finish evaluation and the in-repo
same-data baselines, then revise the joint recipe.  A same-data SOTA
comparison remains the project goal, not a current result.

\section{Proof Sketches and Boundaries}

\subsection{Same-world non-identification}
Let $\mathcal S_0$ be the support of inputs with zero action.  If predictors
$f$ and $g$ agree almost everywhere on $\mathcal S_0$, then for any matched
loss $\ell$, their matched risks are equal by substitution.  Define $g$ to
equal $f$ on $\mathcal S_0$ and take any measurable value on disjoint nonzero
action support $\mathcal S_1$.  Matched risk cannot distinguish the extension.
The result establishes only underdetermination off support.

\subsection{Marginal equality of active quartets}
For a fixed active edge, matched and alternative multisets are
\begin{align*}
Q_+&=\{(\csi_u,\map_u),(\csi_v,\map_v)\},\\
Q_-&=\{(\csi_u,\map_v),(\csi_v,\map_u)\}.
\end{align*}
Projection onto CSI gives $\{\csi_u,\csi_v\}$ for both; projection onto maps
gives $\{\map_u,\map_v\}$ for both.  Direction-symmetric routing and equal
weighting preserve the equality.  Hence a statistic of only one projection
cannot distinguish labels.  A joint identifier is not ruled out.

\subsection{Bayes-risk value of action}
For squared loss, the optimal predictors are conditional means.  Applying the
law of total covariance to $\E[Z\mid S,A]$ conditioned on $S$ yields
\begin{equation*}
 R_{\mathrm{noA}}^*-R_A^*
 =\E\|\E[Z\mid S,A]-\E[Z\mid S]\|_2^2
 =\E\operatorname{tr}\operatorname{Cov}(\E[Z\mid S,A]\mid S)\ge0.
\end{equation*}
Strictness requires action-dependent conditional means on positive measure.
It neither guarantees that a finite network reaches Bayes risk nor that a
learned action embedding retains the raw action.

\section{Complete Sampling and Leakage Contract}

For each optimization draw: sample an eligible bank uniformly; sample a source
node uniformly; sample a common position uniformly without route conditioning;
sample each legal Hamming-1 target branch with positive probability; and reuse
the same observation augmentation, mask, and query across the branch bundle.
Target CSI is loaded only after the source-predictor inputs are finalized.  The
data loader asserts the following no-position allowlist:
\begin{equation*}
\{V_m(\csi_u),G(\map_u),\Delta_{uv},c,m,q\}.
\end{equation*}
It rejects $x$, target CSI, target latent before label construction, route,
effect magnitude, bank/world ID, and any user-centered crop.  The oracle-$x$
loader is a separate code path and checkpoint.

Siblings remain clustered across source-encoder-train, source-method-selection,
source-probe-train, source-probe-selection, source-calibration-fit,
source-calibration-selection, source-final-unseen-bank, target adaptation
support, and final target query.  No partition can be
renamed ``pilot'' to bypass this ledger.

\section{Artifact-to-Claim Checklist}

Before replacing any dash, the artifact must include scene IDs, split role,
route counts, sample denominator, seed, model/input allowlist, checkpoint hash,
configuration hash, sufficient statistics, and failure cases.  Descriptive
localization meters from an executed factorial may appear as a negative or
ablation table.  A success or SOTA claim still requires same-data baseline
meters and does not enter the abstract from the historical negative run
alone.  Specifically: a
wrong-map domain claim needs at least two runnable map-conditioned models;
Response needs teacher agreement and per-scene wins over copy, no-action, and
action-swap; a joint-improvement claim needs both native skills, equal-resource
controls, and meters that beat both single branches; a cross-city improvement
claim needs both target cities; and any simulator-consistent wording needs
qualified RT plus an external engine or controlled real intervention.

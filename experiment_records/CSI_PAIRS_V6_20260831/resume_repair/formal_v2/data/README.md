# Formal dataset location

The default formal configuration resolves its dataset to:

`formal_v2/data/csi_pairs_formal_v2.npz`

You may keep a large dataset elsewhere and set `CSI_PAIRS_FORMAL_DATASET` to its absolute path. Read `formal_v2/DATA_CONTRACT.md` before creating or moving formal data. No fixture or synthetic output may be placed here as scientific evidence.

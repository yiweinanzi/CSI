# 六张论文表的代码接线与修复

当前入口：`python -B -m formal_v2.paper_run`。服务器上可使用 `bash formal_v2/scripts/run_paper.sh DATASET OUTPUT --device cuda:0`，首次自动准备独立 Wi-GATr 环境。配置为 `paper_formal.json`、`paper_all_probes.json`。

代码侧已经接通两张主表、四张附表所需任务，按同一输入配置执行、恢复和导出；不需要 LLM 审批、许可、迁移认证、Python 安装闭包或科学结论通过。旧的未接通六表调度器已删除，`paper_suite` 保留只读历史导出和格式化工具。

## 这次实际修复

- 新训练结果与附表后端的格式断裂：增加直接消费教师和四分支 checkpoint 的控制、地图和风险任务，并统一从实际 CSV 出表。
- 对齐辅助梯度偏弱、响应自适应权重可能进一步主导：新增源域 pilot 梯度尺度归一化，Full 使用静态加权和；原配方保留为 S1 对照。该修复针对观察到的优化失衡，尚不能证明它是全部性能差距的原因。
- 定位头尺度和最佳状态：源域拟合特征/坐标标准化，适配时保持尺度不变；保存与损失对应的正确参数状态。所有比较方法共用此流程。
- 教师读出层和探针原先的全数据更新：新协议改为 minibatch 更新；教师输入、潜变量和探针特征使用磁盘数组，地图编码按批次处理。
- 输入捷径对照重复计算：直接构建 raw CSI/map/metadata 特征，不再调用四个编码器；同一探针每个种子训练一次，特征跨种子复用。
- 原先每一行重新散列整个 bank：现在在当前场景内计算一次，再复用摘要。
- 恢复粒度：教师与读出层、主模型、探针、三个风格基线和 Wi-GATr 保存优化器；PMNet 按 epoch 保存。定位按模型、诊断按单元保存。已完成任务不必从头运行。
- Wi-GATr 尾部微批次会报错、部分基线验证后停留在 eval 模式：修复批次采样与 train/eval 切换，并测试中断恢复。
- RFIR 原先读取全部地图确定材质类别数：改用固定数据元信息，避免利用目标数据决定模型尺寸。
- 跨环境地图诊断：只生成一次共同单位列表，各模型及 Wi-GATr 的旧版官方 PyTorch 共用它。

## 与旧协议不同，论文应同步写明

1. Wi-GATr/PMNet 原本是功率预测方法。主表是“原生逆定位估计作为冻结特征 + 共同位置头”的任务适配，S3 是原生逆定位诊断。不能把它们称作完整的原生 CSI 定位 SOTA 基准。
2. 资源对照取消额外瓶颈，使用共同位置头，报告实际 encoder 参数/FLOP 比例，不能把接近匹配写成精确匹配。
3. 配对打乱使用源域全局排列，保留单位边际分布和响应 query 索引。它不是旧协议的场景内效果分桶排列；后者在单一地图边的分桶里根本不存在。
4. 风险样本按每个 bank 的实际可用类别依照预定比例取样。`mixture.csv` 明示每类数量，包括零。不能声称所有 bank 都具有四类固定比例；无共同支持时报告 N/A，而全查询结果仍保留。
5. 新配方与新小批次预算需要重新运行。不得与旧全批次协议的结果混合宣称提升。

## 验证范围

本地 CPU 测试覆盖真实的小规模四分支训练、源域梯度归一化、尺度变换与冻结、独立探针、资源/打乱对照、真实 SigMap 六条件执行、模型产生的风险特征与校准、恢复与六表导出。
Wi-GATr 训练循环的恢复和小数据尾批次使用明确标注的微型测试模型验证；官方 GPU 算子及全量数据性能仍需服务器测试。PMNet 官方模块的既有前向/反向测试保留。
六表导出测试使用纯合成输入，验证完整性、缺项识别、query/support 一致性、原样输出负结果；它不代表六张正式实验表已经有了新数据。

最终整套测试：**628 passed、28 skipped**（200.79 秒），记录在 `2026-09-09-paper-final-tests.txt`。最后的共享地图单位、教师恢复和导出改动另有 **4 passed** 专项测试，记录在 `2026-09-09-paper-final-targeted-tests.txt`。跳过项涉及 CUDA、平台能力和缺失历史产物。128 个非 vendor Python 文件通过语法检查；两个 Bash 启动脚本通过 Git Bash `-n` 检查；`git diff --check` 通过。没有删除或改写历史 checkpoint 和实验结果。

交付包：`artifacts/CSI-paper-code-20260909.zip`，包含 238 个文件，约 1.1 MB。已在临时空目录解压验证六阶段命令清单和 Wi-GATr/PMNet vendor 源码完整性。包不包含训练数据、checkpoint、正式实验结果或无关文献压缩包。它是直接可解压运行的代码包，不需要发布认证。修改尚未提交或推送 GitHub。

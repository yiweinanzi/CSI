# 实验代码清理

本轮实际删除了 58 个旧文件，共 37,418 行；另外缩减了旧入口和环境认证模块。
逐文件清单见 [code-cleanup-files.json](2026-09-09-code-cleanup-files.json)。这次是物理删除，不只是修改默认开关。

## 删除范围

- LLM 审批、过期许可、运行审批预检及旧全流程启动脚本。
- 迁移申请/认证、迁移证据执行器、旧源码对齐和评估修复认证工具。
- 整个 Python 安装环境的 wheel/RECORD 闭包认证。
- 自动 claims 汇总、文献回执、传播路径审计、第二引擎外部验证与 RT 校准。
- 固定双 GPU、固定旧运行目录的 source pilot 入口；新训练入口提供训练轨迹和梯度诊断。
- 上述流程专属测试、配置，以及匿名发布/冻结证据矩阵构建脚本。混合测试文件中的数据、指标和基线测试继续保留。

## 保留范围

- 数据生成器、数据协议、源域/目标域隔离，teacher、四分支训练与定位。
- 核心独立评测、磁盘数组、小批次探针、断点恢复和表格导出。
- Wi-GATr / PMNet 等基线、配对打乱、资源匹配、表征与捷径对照。
- 风险校准仍服务于 S4；完整评估的额外探针仍服务于附表。没有把这些实验误删为管理代码。
- 文件摘要、防止输出覆盖、完整结果与科学失败检查。部分历史格式字段仍保留用于读表，但不会启动迁移认证。
- 历史数据、checkpoint、结果和审计材料，均未修改或删除。

## 保留入口的修复

`formal_cli` 改为独立实验阶段入口。新实验优先使用 `paper_train` / `paper_core`；CLI 不再提供审批和 `all` 发布链。
环境记录使用 `experiment_runtime.py`，记录 Python、NumPy、SciPy、PyTorch、确定性设置和源码摘要，不检查安装回执或要求 Git 工作区干净。
新记录有独立 schema；旧认证记录不会被伪装为新协议记录。

为兼容保留的表结构，`requirements_lock_sha256` 字段存放依赖版本摘要，并明确附带
`dependency_record_kind=installed-version-summary`。它不再表示 wheel 闭包认证。

另修复了 Windows CSV 目录同步和路径分隔符问题，以及 NumPy 1.x 下风险曲线积分 API 不兼容。
第三方基线的检出换行恢复为 Git 原始字节，并配置 `.gitattributes` 防止再次破坏文件摘要；没有改动基线算法或降低校验要求。
